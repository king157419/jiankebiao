# 上大课表 · 把一周过成喜欢的颜色

本交付是 Android 课程表的视觉主题规范与浏览器预览，不包含 Flutter 代码。六套主题共用信息结构，通过色彩、圆角、字体气质和背景插画形成各自辨识度。先看清今天去哪上课，再感受到主题的温度。

## 1. 文件与使用约定

- `themes.json`：UTF-8、严格 JSON，顶层为六个主题对象的数组。颜色统一使用 `#RRGGBB`，透明度独立配置。
- `preview.html`：直接双击即可离线打开；CSS、JavaScript 与主题 JSON 均内联，插画从同目录 `assets/` 读取，无字体 CDN 或第三方运行依赖。
- `decor.backgroundAsset` 是相对 `assets/` 的文件名；`null` 表示使用纯色或文末的渐变方案。
- `cornerRadius` 使用 dp，字号建议使用 sp；HTML 的 CSS px 仅用于视觉模拟。
- `fontHint` 表示气质，不指定需要下载的字体。优先系统中文字体；圆体不能牺牲小字号可读性，衬线只用于大标题。
- 预览日期、周次、教师、地点、具体上下课时刻均为演示；课程名称采用任务提供的六门示例。12 节及 4/8 节后的分段遵循任务约束，正式应用的作息必须由学校配置提供。
- 上大蓝使用任务指定的 `#1F4E9C`，不是对学校最新品牌规范的认证；不添加未经提供的校徽。

| 主题 | 设计理念 | 适用场景 | 字体与装饰 |
| --- | --- | --- | --- |

| 薄荷奶绿 · mint | 奶绿色留白与植物感，清新但不刺眼，课程色保留冷暖变化 | 白天学习、自习计划、长时间浏览 | rounded；薄荷叶水彩，轻玻璃卡片 |

主题切换只改变视觉 token，不改变课程标识、顺序与位置。同一课程跨周保持同一色槽；以稳定课程 ID 分配色槽，避免每次打开随机配色。超过十门课允许循环色槽，但同时保留课程名与节次，不能只靠颜色区分。

## 3. 色彩与可读性

`primary/onPrimary` 用于实心主按钮；`onSurface/onSurfaceMuted` 用于正文和次级文字；`headerText` 用于星期与标题；`timeColumnText` 用于节次时间；`todayHighlight` 仅作今日列底色。`outline/gridLine` 是弱分隔，不承载正文。`danger` 用于错误信息，必须伴随明确文字或图标，不与“当前时间”混用。

课程名称、地点、教师全部使用 `courseTextOnBlock`，靠字号和字重区分层级，不给教师文字额外降低 alpha。`blockOpacity` 只作用于课程背景，不能给整个组件设置 opacity，否则文字也会变淡。课程背景按 `a × courseColor + (1-a) × underneath` 合成；先合成再计算文字对比度。深色主题使用较低的背景 alpha 表现通透，不提高底色亮度制造刺眼色块。

可读性底板：插画可以覆盖页面背景，但文字密集的课表区域需有稳定的 `surface` 底板；玻璃质感主要由边缘、外层容器和插画透出形成。若让图片直接位于文字下方，则需逐像素复核最差对比度。小组件面对任意桌面壁纸时，正文所在行/网格必须使用不透明主题底板，透明区域留在外缘；不能直接假设半透明白色在所有壁纸上都安全。

课程十色涵盖粉、橙、黄、绿、青、蓝、紫及灰调，保持同主题内 HEX 不重复。浅色主题用深色字，深色主题用浅色字。颜色只是辅助编码；色觉差异用户仍能通过课程名、星期与节次定位。主题按钮使用选中标记与 `aria-pressed`，键盘焦点需明显，不能只用底色变化表达状态。

对比度计算遵循 sRGB 线性化：通道值归一化后，≤0.04045 时除以 12.92，否则取 `((c+0.055)/1.055)^2.4`；相对亮度 `L=0.2126R+0.7152G+0.0722B`；对比度为 `(L较亮+0.05)/(L较暗+0.05)`。本交付以正文至少 4.5:1 为门槛，小号教师和时间文字同样执行此门槛。配色通过并不等于完成整个应用的 WCAG 认证。

## 4. 课表页布局

### 顶部与星期栏

手机内容区左右边距 16 dp，状态栏与导航栏安全区另外计算。首行显示「上大课表」与学期信息；第二行是上周按钮、当前周次/日期范围、下周按钮和“回到本周”。按钮点击区域至少 48 × 48 dp，周次标题 20–22 sp / 600，辅助日期 12–13 sp。切换周次后保留纵向阅读位置；跨学期时明确更新学期名。

星期栏高 48–56 dp，显示周一至周日及日期。今天使用 `todayHighlight` 贯穿本列，日期以 `primary/onPrimary` 圆角胶囊强调，并提供“今天”语义。周末无课仍保留列结构。星期栏与左侧时间列在滚动时固定。

### 12 节网格与长间隔

左侧时间列宽 44–52 dp，节次 12 sp / 600、起止时间 10–11 sp；全屏可读性优先时放大到 12 sp。每节基础高度建议 52–60 dp；1–4 节为上午，5–8 节为下午，9–12 节为晚上。第 4 节后插入 24–32 dp 的午间带，第 8 节后插入 20–28 dp 的晚间带，标注“午间休息 / 晚间休息”；它们不计入 12 节。视觉间距不表示真实休息时长。

七日课表在窄屏不能同时保证所有课程详情可读。默认手机产品可用精简课程名与地点；提供横屏或放大查看。本 HTML 为设计检视而设，保持最小网格宽度并在课表内部横向滚动，不能让整页横向溢出。放大字体后应允许纵向增长或详情展开，禁止让长标题覆盖相邻列。

### 课程块与文字层级

课程块外间距 3–4 dp，内边距 8–10 dp；圆角读取主题 `cornerRadius`。课程名 13–14 sp / 600，最多三行；地点 11–12 sp / 500；教师 10–11 sp / 400。层级为「课程名 > 地点 > 教师」，教师紧张时先隐藏，详情页完整展示。课名不能只剩没有上下文的单个汉字。跨两节课程合并为一个块，但跨午间/晚间休息的排课应分段绘制并保留同一课程色槽。

单击课程进入详情；辅助读屏标签按“星期、节次、课程、地点、教师”组织。相邻课程发生冲突时并排显示或使用冲突标记，不静默遮盖。正文不以阴影代替对比度。

### 当前时刻指示线

使用 `accent` 的 2 dp 横线，左端小圆点，配带时间文本的标签；只出现在真实今天这一列，并把标签放在空白/边缘区以免遮住课名。线条位置按学校配置中的当前节次起止时刻线性插值，不能把所有小时均分到 12 节。在午休/晚休时将指示线定位在对应间隔带，课外时间不画线；非本周不显示“现在”。浏览器预览固定演示时刻，明确注明“演示”，不伪装成实时排课。

## 5. Android AppWidget 规格

4×2、4×4 指桌面格数，实际像素受启动器、设备密度和系统留白影响。下列尺寸是参考内容区，不是跨设备固定尺寸。

| 项目 | 4×2「今日课程」 | 4×4「本周课表」 |
| --- | --- | --- |
| 参考内容区 | 320 × 156–180 dp | 320 × 320–360 dp |
| 外圆角 | 24 dp；跟随系统允许的圆角裁切 | 24 dp；内部课程块 6–8 dp |
| 内边距 | 16 dp，列表行间 8 dp | 12 dp，列间 2–3 dp |
| 标题 | 15 sp / 600，“今日课程”+日期 | 15 sp / 600，周次+日期范围 |
| 主信息 | 课程名 13 sp / 600，时间 11–12 sp | 日期 11 sp，课程短名 10–11 sp / 600 |
| 辅助信息 | 教室 11–12 sp，主题正文色 | 节次 10 sp，紧凑版省略教师和地点 |
| 行/网格尺寸 | 每行 40–44 dp，优先显示接下来两门 | 星期栏 28 dp，12 行每行约 18 dp，长间隔 8 dp |
| 外层背景不透明度 | glass 0.90，paper 0.98，flat 1.00 | glass 0.94，paper 0.98，flat 1.00 |
| 文字底板不透明度 | 每条列表行 1.00 | 完整课表内容区 1.00 |

这里“背景透明度”按 alpha/不透明度说明：0.90 即 90% 不透明、10% 透明。深色同样使用主题 `surface`；不对文字本身降低透明度。玻璃样式不依赖桌面实时背景模糊；采用预合成底色、细边框与轻微高光即可表达。预览中的阴影为视觉建议，正式 AppWidget 需在目标启动器核实边界裁切。

4×2：左上标题，右上日期；行首竖向课程色条，左侧上课时间，右侧课程名和教室。过去课程折叠，优先下一门；超过两门显示“还有 N 门”，点击打开当天课表。无课则用一句“今天没有课程，留一点时间给自己”。不把导入错误显示成无课。

4×4：标题之下七日网格，今天用底色和日期胶囊双重提示。保留 12 节与两段休息带，课程使用有辨识度的短名（如“高数 A”），课程详情由点击后在应用中呈现。字号放大或组件缩小时，改为当天/未来课程列表以保留可读性，不能把正文无限缩小。更新事件、点击行为与时间同步是后续 Android 实现工作。

## 6. 状态插画与文案

| 状态 | 小插画/表情 | 文案与操作 |
| --- | --- | --- |
| 尚未导入课表 | 打开的空白小本子、🌱，局部使用主题 accent | “新学期，从第一门课开始。”主按钮“导入课表”，次入口“手动添加” |
| 导入成功 | 书页上一个勾、✨，避免整屏礼花 | “课表已准备好。”显示导入课程数量与学期，按钮“查看课表” |
| 周末无课 | 休息的小云或一杯茶、☁️ | “周末留白，也是一种安排。”保留查看下周入口 |
| 导入失败 | 折角纸张+小问号 | “暂时没有读到课程。”显示具体原因与“重新导入”，不能仅展示表情 |

插画尺寸建议 72–104 dp，周边至少 16 dp 留白；插画是装饰，辅助技术可以忽略，状态含义由文字完整表达。成功动效建议 180–240 ms 淡入，开启减少动态效果时直接显示静态状态。现有三张 PNG 是页面背景，不冒充独立状态插画。

## 7. 背景插画与降级方案

三张背景使用内置 imagegen 生成，要求竖版、低对比、无文字、中央约 80% 留白。保留生成原图，不通过放大伪造清晰度。尺寸与实际验证结果见下方交付检查。

背景建议 `cover` 裁切并居中；装饰只在边角，裁切不应损失信息。浅色壁纸不能放到深色主题，夜空也不能复用到浅色主题。应用可提供“关闭背景插画”选项以恢复纯色。

图片缺失、低内存或用户关闭插画时，使用以下 CSS/Flutter 等价渐变参数；角度仅是 CSS 的表示方式，Flutter 可换成同方向的端点，不在本交付写 Flutter 代码：

| --- | --- | --- |
| 樱花粉 | 160°，左上至右下 | 0% `#FFF7FA`、65% `#FFF9FB`、100% `#F4DDE7` |
| 薄荷奶绿 | 160°，左上至右下 | 0% `#F3FAF5`、65% `#F7FBF7`、100% `#DCEFE4` |

### 预览检查结果与实现边界

- 严格 JSON 解析通过：6 个主题、每主题 15 个颜色 token、10 个课程色；字段、颜色格式、中文与表情编码有效。
- HTML 内联 JSON 与 `themes.json` 深度比较完全相同；没有 `fetch`、外部 CSS/JS 或字体服务依赖。
- Microsoft Edge 无头浏览器以本地 `file://` 打开；6 个主题按钮均切换成功、选中状态正确，没有 JavaScript 异常。
- 1440 px 桌面与 390 px 窄屏检查通过：7 天、12 节、2 段长间隔、6 门课程；没有整页横向溢出或课程文字裁切，窄屏课表内部可横向滚动。
- 浅色、深色与窄屏截图已人工检查：当前时间使用 accent，仅覆盖今日列且在课程文字后方；演示时间放在顶部，避免遮挡。4×2 节次标记保持一行，奶油杏只对标题采用衬线气质。
- HTML 是多主题对照设计展示，不是 Android 真机等比例截图；其中网格为紧凑展示尺寸，正式产品采用第 4/5 节的 dp/sp 建议。预览固定一周数据；周次导航、课程点击、导入、系统字体缩放和真实 AppWidget 更新不在本交付实现范围。
- 本次简化：共用一份主题数据与课程结构；使用不透明文字底板消除对桌面背景模糊的依赖；没有添加第三方依赖。后续在真实 Android 设备和启动器上验证动态字号、安全区与小组件尺寸。

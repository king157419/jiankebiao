# 简课表

一个干净的大学课程表 App（Android）。**无广告、无账号、不上传任何数据**，所有课表都只存在你自己的手机里。

- **教务一键导入**：在学校自己的教务网页里登录，点一下就把本学期课表读进来（目前内置支持正方教务，上海大学已验证；其他学校可以输入教务网址尝试）；导入时自动识别或按学校校历设置开学日期（含开学前 28 天内预导入），也可以直接选「现在是第几周？」（1.5.0）
- **导不进来也不怕**：手动录入有「保存并继续添加」「复制到其他星期」「教师 / 教室自动补全」「长按空格子新建」；还没有课时，周课表直接给出「从教务导入 / 手动添加」两个入口（1.5.0）
- **好看的周课表**：整屏铺满无底栏、今天整列高亮、正在上的课带进度、单双周、午间 / 晚间休息带按作息自动画，点顶部「第 N 周 ▾」即可选择或校正当前周次
- **调休 / 停课**：国庆调休「周六上周一的课」、运动会停课，按日期设置一次，周课表、桌面小组件、上课提醒一起生效。导入课表后会按学校校历提示**一键套用**放假 / 调休（1.5.0）；在周课表里**长按某一天的列头**也能快速设置，停课日标「休」、补课日标「补」，关掉周末显示时补课的周六也会单独显示出来；内置假期表会随检查更新联网刷新（内容只有日期）
- **上课提醒**（1.4.0）：上课前 5 / 10 / 15 / 20 / 30 分钟在通知栏提醒，前一天晚上预告明天几节课、停课还是调休；提醒完全在本机生成、不联网，默认关闭
- **桌面小组件**：4×2「当天课程」，◀ ▶ 切换日期，课多了上下滑动；头部写着「上课中 · 至 11:50」「42 分钟后上课」，今天的课上完自动改看明天（1.4.0）；2×1「下一节课」只显示正在上或接下来的一节（1.4.0）；在「设置 → 添加桌面小组件」面板里两种小组件都能一键添加到桌面，弹不出确认框时按手机品牌给手动步骤（1.5.0）
- **导出到日历（.ics）**（1.4.0）：整学期的课一节一节导进 iPhone / Outlook / Google 日历，调休、停课已经算好，可以带课前提醒
- 6 套主题、多课表、作息 / 开学日期 / 总周数随便改、备份与恢复、每天最多一次的新版本提醒（依次尝试 Gitee 镜像、jsDelivr、GitHub；发布者只改一处仓库配置，见「十一」）

> 1.3.0 起 App 改名为「简课表」（以前叫「上大课表」）。包名没变，**直接覆盖安装，课表不会丢**。

## 给朋友装：安卓、鸿蒙、iPhone

先看朋友的手机是哪一种：

- **安卓手机**（小米、OPPO、vivo、荣耀、三星等），以及**华为手机上 HarmonyOS 4.x 及更早的版本**：能直接装，看「安卓」。
- **华为手机上 HarmonyOS 5.0 及以后**（也就是纯血鸿蒙，包括 6、7）：要借「卓易通」（华为给纯血鸿蒙做的安卓应用兼容工具）才能装，看「纯血鸿蒙」。版本号在「设置 → 关于手机」里看。
- **iPhone**：装不了，只能换个办法用，看「iPhone」。

### 安卓

1. **把安装包发给他**。最省事是你用微信或 QQ 直接把 `简课表-v1.5.0-arm64.apk`（约 21.5 MB）发过去。也可以让他用手机浏览器打开下载页 https://jiankebiao.vercel.app/ 自己下，但 `*.vercel.app` 这个域名在大陆网络和微信里通常打不开，国内朋友基本只能靠你发文件。
2. **微信收到的要改名**。微信会把文件名改成 `…apk.1`，这样点不开。到「文件管理 → 最近」里长按它，重命名，把末尾的 `.1` 删掉。
3. **点开 APK，允许安装**。Android 8 及以上会提示「不允许安装来自此来源的应用」，点「设置」，给你用来打开 APK 的那个 App（微信、QQ、文件管理或浏览器）打开「安装未知应用 / 允许来自此来源」，返回继续。各品牌的菜单名见下面「一、下载与安装 → 2」。
4. **华为 / 荣耀的老系统先退出纯净模式**：EMUI 12、HarmonyOS 2 到 4 默认开着纯净模式，会直接拦下来，退出办法同样见「一、下载与安装 → 2」。
5. 提示「此应用未经检测 / 可能有风险」选「继续安装」。打开后直接从首页「从教务导入」开始。

装 arm64 包提示「解析包错误」时，说明手机比较老，改发 `简课表-v1.5.0.apk` 通用包（约 59 MB）。

### 纯血鸿蒙（HarmonyOS 5.0 及以后）

纯血鸿蒙自己不能装 APK，要通过「卓易通」。华为官网写明这条路适用于 HarmonyOS 5.0 及以上的手机和平板；卓易通在 2026-07-01 宣布已适配 HarmonyOS 7。

1. 在华为「应用市场」里搜「卓易通」，装上，第一次打开按它的提示走完。
2. 用微信或 QQ 把 `简课表-v1.5.0-arm64.apk` 发给他。
3. 微信收到的文件同样要改名：「文件管理 → 最近」里长按它，重命名，删掉末尾的 `.1`，改回 `.apk`。
4. 点开这个 APK，由卓易通安装。装好后在卓易通里打开简课表。

能不能装以卓易通的判定为准（华为官网原话）。网上的说法是它拦的是已经有鸿蒙原生版的应用（非官方说法），简课表没有鸿蒙版，按理不在拦截范围内。**但简课表在卓易通里还没有实测过**：能不能正常打开、教务一键导入（要在 App 里打开学校登录页）、桌面小组件能不能用，都不知道。一键导入用不了时，可以直接手动录入课程（见「三、导不进来怎么办」第 1 条），或用同班安卓同学在「设置 → 备份与恢复 → 导出备份文件」导出的备份在「从备份文件恢复」里选「合并」。

简课表的鸿蒙原生版现在没有。

### iPhone

iPhone 装不了 APK，简课表也没有 iPhone 版。有两个办法：

**办法一：装别的课表 App。** WakeUp课程表有 iOS 版（App Store 搜「WakeUp课程表」），也支持从教务导入。这条最省事，但就不是简课表了。

**办法二：把简课表的课表转成 iPhone 日历。** 课会一节一节出现在 iPhone 自带的「日历」里，调休、停课已经算好。

1. 找一位用简课表的安卓同学（同班的课表几乎一样），在「设置 → 导出到日历（.ics）」（或「设置 → 课表管理 → 课表右边的 ⋮ → 导出到日历（.ics）」）点「生成并分享」，把生成的 `.ics` 日历文件发过来。
2. 把 `.ics` 送到 iPhone 上。比较稳的是当邮件附件发给他，在 iPhone 自带的「邮件」里点开附件；也可以存到 iPhone「文件」里点开它。
3. 出现日历预览后点「添加全部」（有的版本叫「全部添加」）。建议先在「日历」里新建一个叫「课表」的日历，导入时选它，换学期时整个删掉就行。

办法二的限制：这是一份快照，之后调课、改教室都要重新导一遍；没有一键导入，也没有简课表的小组件。微信里收到的 `.ics` 能不能直接导进日历、离线版在手机上好不好用，都还没在真机上试过。

> 以上 2026-09-29 核对过：华为官网「HarmonyOS 5及以上应用下载安装介绍」（consumer.huawei.com/cn/support/content/zh-cn16061787/，适用版本、微信 `.1` 后缀、「以卓易通实际支持为准」）；IT之家 2026-07-01「卓易通官宣全面支持华为鸿蒙 HarmonyOS 7.0 系统」（ithome.com/0/971/261.htm）；WakeUp课程表官网 wakeup.fun（鸿蒙 NEXT、iOS、Android 三个版本）；Android 开发者文档 alternative-distribution（Android 8.0 起按来源授权「安装未知应用」）；jkb-ics.vercel.app 当天能打开，用示例课表走到了「下载 .ics」这一步。

## 一、下载与安装

### 1. 选哪个安装包

| 文件 | 用途 |
|---|---|
| `简课表-v1.5.0-arm64.apk` | **绝大多数人用这个。** 2018 年以后的安卓手机基本都是 arm64，体积约 21.5 MB，只有通用包的三分之一多 |
| `简课表-v1.5.0.apk` | 通用包（arm64 / armeabi-v7a / x86_64 都在里面），约 59 MB。装 arm64 包提示「解析包错误」「应用未安装」，或装上后一打开就闪退（少数 32 位老手机）时改用它 |

两个包功能完全一样。不确定就先装 arm64 的，装不上再换通用包。

下载页：https://jiankebiao.vercel.app/ （只有 arm64 包；`*.vercel.app` 在大陆网络和微信里通常打不开，国内朋友请直接用微信 / QQ 发 APK 文件，见上面「给朋友装」）。GitHub Releases 发布时补上链接。App 里的「设置 → 检查更新」也会在有新版时直接带你去下载页。

### 2. 允许安装「未知来源」的应用

不是从应用商店装的，系统会拦一下，按手机品牌操作（不同系统版本的菜单名可能略有差别）：

- **通用（Android 8 及以上）**：点开 APK → 提示「不允许安装来自此来源的应用」→ 点「设置」→ 打开「允许来自此来源」→ 返回继续安装。这个开关是**给某个 App 的**（比如「文件管理」或浏览器），装完可以再关掉。
- **华为 / 荣耀**：
  - 先看**纯净模式**：EMUI 12 / HarmonyOS 2~4 默认开着「纯净模式」，会直接拦下商店外的应用。到「设置 → 系统和更新 → 纯净模式」点「退出」（部分版本在「设置 → 安全」里），装完可以再打开。
  - 再允许外部来源：「设置 → 安全 → 更多安全设置 → 外部来源应用下载」，给你用来打开 APK 的 App 打开开关。
  - **HarmonyOS 5.0 及以后（纯血鸿蒙，包括 6、7）不能直接安装 APK**，要通过「卓易通」安装，简课表在里面还没实测，步骤见上面「给朋友装 → 纯血鸿蒙」。
- **小米 / 红米（MIUI / HyperOS）**：安装时如果提示风险，选「继续安装」；可能要求等待几秒或登录小米账号。也可以在「设置 → 隐私保护 → 特殊权限 → 安装未知应用」里给对应的 App 打开。
- **OPPO / 一加 / realme（ColorOS）**：安装时会做「安全检测」，等它扫完点「继续安装」；如果被拦，在「设置 → 安全 → 安装外部来源应用」里打开。
- **vivo / iQOO（OriginOS）**：「设置 → 安全与隐私 → 更多安全设置 → 安装未知应用」，给对应的 App 打开；安装时提示风险选「继续安装」。

提示「此应用未经检测 / 可能有风险」是所有商店外 APK 的通用提示，选「仍然安装」即可。

### 3. 升级

直接安装新版 APK 覆盖即可，课表、主题、设置都会保留（包括从「上大课表」1.2.0 升级到「简课表」）。上课提醒默认关闭，需要时到「设置 → 上课提醒」打开。
**请始终用同一个来源的安装包**：签名不同的包系统会要求先卸载旧版，卸载会清空课表——真遇到这种情况，先在「设置 → 备份与恢复」里导出一份备份。

## 二、第一次打开

打开即进入全屏周课表（右上角齿轮打开设置，⋮ 菜单可从教务导入、新建课程、选择 / 校正周次）。1.5.0 起去掉了首次启动的隐私同意弹窗；完整隐私说明随时能在「设置 → 隐私说明」里查看。

## 三、从教务系统一键导入

入口：首页空状态的「从教务导入」，或周课表右上角 ⋮ →「从教务导入」。

1. **选学校**：可以按校名、拼音、拼音首字母搜索。列表里的标签：
   - **已验证**：开发者实际走通过；**社区 / 实验**：按同类系统推断，可能要多试几次。
   - 学校不在列表里：点最下面的「我的学校不在列表」，输入教务系统的网址（登录后浏览器地址栏里的那个）。App 能认出正方新版教务（网址里有 `/jwglxt`）时会按实验模式尝试；认不出会告诉你暂不支持，并说明怎么反馈。
2. **登录**：App 打开学校自己的登录页，用**你自己的账号**登录。账号密码直接发给学校，App 不读取也不保存。短信验证码、滑块等二次验证在页面里正常完成即可。
3. **点底部的「一键导入课表」**。按钮一直是灰的、但你确定已经进入教务系统了，就点下面那行「我已登录，直接导入」。
4. **在预览页逐项核对**（别一路点确认）：
   - 学生姓名是不是你本人；学期名是否和教务系统一致；
   - **开学日期**：教务系统识别到当前周次时直接推算；否则若学校有校历（覆盖今天或 28 天内即将开学），自动按校历预设并在点「确认导入」时问一次确认；都没有时弹出「现在是第几周？」供选择；
   - **作息时间**：默认沿用当前课表的作息，也可以换成模板；
   - 课程数量、抽查几门的星期 / 节次 / 周次 / 教室；展开「N 条提醒」看看有没有被跳过的课；
   - 「没有固定时间的课」（实践课、线上课）不会进网格，需要时手动添加。
5. 选「覆盖当前课表」或「新建课表」→ 确认。

导入完成（或离开登录页）后，App 默认会清掉教务网页的登录状态，拿到你手机的人不能直接进教务系统。想少登几次，可以在「设置 → 记住教务登录」里打开。

### 扫码登录（企业微信 / 微信 / QQ）

有些学校的统一身份认证提供「企业微信 / 微信 / QQ 扫码或一键登录」。1.3.0 起在登录页点这些按钮，App 会**跳到对应的 App**（手机上要装了它），在那边确认后回到简课表继续。
如果提示「没有找到能打开这个登录方式的 App」，说明手机上没装，或者学校的这个入口只能在电脑上扫码——**改用账号密码登录**即可。

### 导不进来怎么办

按这个顺序试：

1. **手动录入**（一学期大约 10 分钟）：
   - 在周课表上**长按空格子**，直接新建这一天、这一节的课；
   - 编辑页底部的 **「保存并继续添加」**：保存后留在本页，星期 / 节次 / 周次都保留，只清空课程名、教师和教室，适合连着录同一天的课；
   - **「复制到其他星期」**：一门课一周上两三次，勾上其他几天，一次生成，改颜色时一起变；
   - 教师、教室输入时会**提示本课表里用过的值**。
2. **导出导入记录帮忙适配**：导入失败的对话框里、或登录页右上角 ⋮ 里有「导出导入记录」。它会在你手机上把学号、手机号、姓名等替换成 `***` 后生成一个文件，由你自己决定发给谁（可以先打开检查），App 永远不会自动上传。连同学校名称、教务网址一起通过「设置 → 反馈」发给开发者。

## 四、桌面小组件

**推荐：在 App 里直接添加。** 打开「设置 → 添加桌面小组件」，面板里有「当天课程 · 4×2」和「下一节课 · 2×1」两张带预览图的卡片，点任意一张的「添加到桌面」，系统会弹出确认框，点「添加」就放好了（卡片下方会显示「已添加到桌面 ✓」）。

桌面没弹出这个确认框时，点开面板底部的「没弹出确认框？看看怎么手动添加」，会按你的手机品牌给出步骤：

1. 回到桌面，**长按桌面空白处**（华为 / 荣耀在桌面双指捏合）；
2. 点「小组件」（小米叫「添加小组件 / 小部件」，vivo 叫「原子组件 / 小组件」，华为叫「窗口小工具 / 服务卡片」）；
3. 在列表里找到「**简课表**」；
4. **长按预览图，拖到桌面空位**。

有两个小组件：

| 小组件 | 尺寸 | 内容 |
|---|---|---|
| **简课表**（当天课程） | 4×2，可调 | 某一天的全部课程，◀ ▶ 切换日期（翻到别的日子时右上角有「回到今天」），课多了可以上下滑动，也可以把小组件拉高 |
| **下一节课**（1.4.0） | 2×1，可调 | 正在上或接下来的一节课：课程名、时间、地点；今天没课了显示之后 7 天内第一个有课的日子的第一节（标「明天」「周一」，正好一周后标日期），都没有时显示「近期没有课程」 |

1.5.0 起两种小组件都能在「设置 → 添加桌面小组件」面板里一键添加，也可以从桌面的小组件列表拖出来。

1.4.0 起 4×2 的头部会跟着时间变：「第 4 周 · 上课中 · 至 11:50」「第 4 周 · 51 分钟后上课」（90 分钟以内）「第 4 周 · 下一节 10:00」；今天的课都上完了（或者今天没课、已经过了 18:00）就自动改看明天，头部写「明天 · 第 4 周 · 3 节课」；这时点 ◀ 还能翻回今天（头部写「今天 · 已结束」），点「回到明天」或 ▶ 回来。停课日照旧显示「今天停课」和备注。

每天 0 点自动换到新的一天；改了课表、调休或主题后 App 会主动刷新它；另外小组件会在每节课开始 / 结束、开课前 90 分钟、18:00 这些时刻自己刷新一次（用的是系统的普通闹钟，不需要精确闹钟权限，所以可能晚十几到几十分钟（系统省电策略所致）；屏幕关着时等亮屏再补）。很久没打开 App 时会显示「打开 App 刷新课表」。

## 五、调休与停课

「设置 → 学期设置 → 调休 / 停课 → 添加调休 / 停课」：

1. 选**日期**；
2. 选这一天怎么上课：
   - **停课**：这一天的课全部不显示（放假、运动会）；
   - **按某个星期上课**：例如国庆后的周六「按周一的课上」；需要的话还能同时指定按第几周；
   - **指定周次**：例如「这一天按第 7 周的课上」（补课），星期可以不变或另选；
3. 备注（可选），例如「国庆调休」。

更快的办法（v1.4.0）：在周课表里**长按某一天的列头**（星期 + 日期那一格），弹出这一天的面板：标题写着「10月8日 周四 · 第 4 周」和这一天现在的状态；假期表里对这一天有安排时，最上面一行是「假期表建议：按 10/7（周三）课表上课」或「假期表建议：停课（国庆节）」，点一下就套用；下面是「设为停课」（一键，底部提示里可以「撤销」）、「调休：按某天课表上课」（打开上面的编辑页，已经选好「按某个星期上课」）、「编辑…」，这一天已经有设置时还有「清除设置」。国家调休上班日（例如 10/10 周六）假期表只知道要上班、不知道按哪天的课，点建议行会直接打开编辑页让你选。

设置好的日子在周课表的日期旁边有一个小角标：停课是灰色的「休」，调休 / 补课是主题色的「补」；小组件也会同步显示「停课」和备注。点列表里的一条可以修改，右边的垃圾桶删除（删错了可以点「撤销」）。

学期设置里关掉「显示周末」以后，平时只显示周一到周五；但某一周的周六 / 周日有课（例如补课按周三上课）或者有调休 / 停课设置时，那一周会把这一天单独显示出来，方便看到和长按。

调休 / 停课同样作用于上课提醒（停课的日子不提醒，「接下来的提醒」里写「停课 · 不提醒」；补课日按补的那天的课提醒，正文带「调休：按第 N 周周X上课」）和「导出到日历（.ics）」。

1.5.0 起，已收录校历的学校在导入完成后（或启动发现尚未套用时）会弹出「按××校历」面板，点「一键套用」即可一次写入本学期全部放假 / 调休（过去的条目自动折叠汇总，用户或教务确认过的开学日期不会被推翻）。学期设置里的「套用节假日安排」页仍保留作为手动入口：课表来自已收录的学校时按学校通知，否则按国家法定节假日，逐条勾选后写入。页面顶部写着当前假期表的版本（「假期表 · 内置 2026-10-06」，联网更新过之后是「假期表 · 已更新 …」）；配置了更新源时检查更新成功会顺带刷新假期表（24 小时最多一次），未配置更新源时隐藏手动刷新按钮。

## 七、隐私

- **零上传**：没有服务器、没有账号、没有广告和统计 SDK。课表、作息、设置只存在手机的 App 私有目录里，卸载即全部删除。
- **只在这几种情况下联网**：你主动「从教务导入」时打开学校教务网页；每天最多一次检查新版本（依次尝试 Gitee 镜像、jsDelivr、GitHub，下载一个很小的 `latest.json`）；检查成功后顺带更新假期表（同一个仓库里的 `holidays.json`，内容只有日期，24 小时最多一次；配置了更新源时「套用节假日安排」页也可以手动刷新）。上课提醒、导出日历都在本机完成，不联网。这些请求都不带任何个人数据，但对方会看到你的 IP。学校清单内置在安装包里，不联网下载。
- **权限**：App 自己申请 `INTERNET`（联网）；1.4.0 起为「上课提醒」加了 `POST_NOTIFICATIONS`（发通知，Android 13 及以上只在你打开上课提醒或点测试时弹窗询问）、`USE_EXACT_ALARM`（精确闹钟，Android 13 及以上安装时系统直接授予，只用于让上课提醒准点送达）、`SCHEDULE_EXACT_ALARM`（同样是精确闹钟，只在 Android 12 / 12L 上声明，用户可以在系统里收回；收回后提醒最多可能晚 1 小时，可在「上课提醒」页提示卡里去系统设置重新打开「闹钟和提醒」）、`VIBRATE`（振动）、`RECEIVE_BOOT_COMPLETED`（手机重启后把排好的提醒交回系统闹钟）。另有 3 个由系统组件自动合并进来的普通权限（`ACCESS_NETWORK_STATE`、`WAKE_LOCK`、`FOREGROUND_SERVICE`，来自小组件库引入的 Android 官方后台任务库），安装时自动授予、**不会弹窗**，App 没有用它们做额外的事。没有存储、相机、位置、通讯录等敏感权限。
- 完整内容见 App 内「设置 → 隐私说明」（源文件 `shu_schedule/assets/privacy.md`）。

## 八、常见问题

**周次不对 / 开学日期不对？**
直接点周课表顶部的「第 N 周 ▾」→ 底部的「本周不是第 N 周？点这里校正」，选现在是第几周即可自动算出第一周周一（也可以在「设置 → 学期设置 → 按当前周次设置」里改）。

**总周数不对 / 后面几周的课不显示？**
「设置 → 学期设置 → 总周数」改大。

**上课时间和学校不一样？**
「设置 → 作息时间」逐节改；午间 / 晚间休息带会按作息自动画（相邻两节间隔 40 分钟以上的地方）。

**导入失败的常见提示**

| 提示 | 怎么办 |
|---|---|
| 未登录 / 登录已失效 | 回到教务首页重新登录，看到教务系统菜单后再点导入 |
| 请求教务接口失败 / 网页加载失败 | 多半是网络：不少学校**校外访问教务要连学校 VPN**，连上校园网或 VPN 再试 |
| 抓取超时 | 教务系统太慢，确认网页里能看到课表后稍等再试 |
| 没有解析到任何课程 | 教务默认选中的学期不对，在网页里手动切到正确学期查询一次，再点导入 |
| 教务系统返回的内容看不懂 / 接口可能已经变化 | 可能还没登录成功，或学校改了系统，请导出导入记录并反馈 |

实在导不进来，看上面「导不进来怎么办」：手动录入、导出导入记录。

**小组件的「正在上 / 下一节」更新不及时？**
1.4.0 起小组件会在每节课开始 / 结束等时刻自己刷新，但用的是系统的普通闹钟（不精确），可能晚十几到几十分钟（系统省电策略所致），屏幕关着时要等亮屏；被省电策略限制时会更久。打开一次 App 会立刻刷新。App 不会为小组件申请自启动权限，也不给小组件用精确闹钟（精确闹钟只给「上课提醒」用）。

**上课提醒没响 / 晚了？**
先在「设置 → 上课提醒」点「发送测试提醒」：收不到说明通知权限被关了，点顶部提示卡的「去允许通知」打开。Android 12 上如果在系统里收回了「闹钟和提醒」，页面会显示「提醒可能不准时」提示卡，提醒最多可能晚 1 小时，点卡片去系统设置重新允许「闹钟和提醒」即可。「1 分钟后测试」能到只说明通知和定时链路正常，不能说明没有精确闹钟时正式提醒也准点（离现在越远的提醒，系统可以推迟得越多）。

- **提醒只排接下来 14 天**，每次打开简课表都会往后补上；第 14 天晚上（预告时间）会收到一条「提醒已排到 x月x日，打开简课表就会续上」，打开一次 App 就续上，一直不打开就不会再有新的提醒。
- **提醒跟着当前课表走**：「上课提醒」页顶部写着「提醒跟随当前课表：…」。切换课表或重新导入后，提醒也换成那张课表的，App 会提示「上课提醒已切换到「…」」。
- **关机期间错过的提醒**会在开机时一起弹出来（通知组件开机后把排好的提醒重新交给系统，已经过点的会立刻触发）。
- 同时有好几条提醒时，系统可能把它们**折叠成一组**；点开组里的某一条会回到周课表本周，点折叠后的组标题只会打开 App。
- 部分手机的省电 / 清理后台策略可能拦截提醒（还没在这些机型上实测）。

**同一时间有两门课？**
网格里画第一门，右上角有 `+N` 角标，点开详情能看到全部。

**会不会上传我的课表？**
不会。见上面「隐私」。

**怎么反馈问题？**
「设置 → 反馈」：复制诊断信息，连同问题描述、截图一起发给开发者（GitHub 地址发布时补上）。导入相关的问题请附上导入记录。会用电脑的话，也可以附一份日志：

```bash
adb logcat -c
# ……在手机上把出问题的操作重做一遍……
adb logcat -d -s flutter chromium > jiankebiao_log.txt
```

1. 只有 Android 安装包。纯血鸿蒙可以试「卓易通」（还没实测）；iPhone 装不了，可以把课表导出成 `.ics` 日历文件导入 iPhone 日历。见「给朋友装」。

## 十一、发布（维护者）

**发布前替换清单：仓库地址只改 `shu_schedule/lib/core/repo_config.dart` 一处。** 把 `kRepo` 里的 `githubOwner: 'OWNER'`、`githubRepo: 'REPO'` 换成真实的 GitHub 仓库；在 Gitee 上有同步镜像的话再填 `giteeOwner` / `giteeRepo`（国内网络优先走 Gitee）。「检查更新」的 `latest.json` 地址、远程假期表地址、「设置 → 反馈」里的 GitHub 链接都从它派生；没换之前 App 不发任何更新 / 假期表请求，设置页隐藏「检查更新」和假期表联网刷新按钮。

App 读文件的顺序：Gitee raw（若配置）→ `cdn.jsdelivr.net/gh/<owner>/<repo>@<branch>/…` → `raw.githubusercontent.com/<owner>/<repo>/<branch>/…`。检查更新以第一个成功的为准；假期表在某个地址「不比手里的新」时会接着试下一个（镜像滞后不挡更新），同一地址的 `latest.json` 和 `holidays.json` 并发读，整次刷新最多 10 秒。所以 `latest.json` 放在仓库根目录、`kRepo.branch`（默认 `main`）分支上。

生成 `latest.json`（Python 3，只用标准库；Windows 上用 `D:/conda/miniconda3/python.exe`）：

```bash
# 在仓库根目录
python shu_schedule/tool/gen_latest.py \
  --apk "dist/简课表-v1.5.0-arm64.apk" --apk "dist/简课表-v1.5.0.apk" \
  --changelog "校历一键套用\n自动识别开学周次" \
  --out dist/latest.json
```

- 版本号默认读 `shu_schedule/pubspec.yaml` 的 `version: x.y.z+N`，也可以 `--version 1.5.0+10`；App 比的是 `+` 后面的 versionCode。
- 第一个 `--apk` 的 SHA-256 写进顶层 `sha256`（建议把 arm64 包放第一个）；两个包的文件名、字节数、SHA-256 都写进 `apks`。
- `holidays` 一段是 `shu_schedule/assets/holidays.json` 的 SHA-256 和 `updatedAt`。App 联网下载节假日表后会核对这个 SHA-256（检查更新拿到的那份对不上时，再看同一地址的 `latest.json`），不一致就拒绝。
- **APK 不要提交进仓库，只放到 GitHub / Gitee 的 Releases。** App 经 jsDelivr 读仓库里的 `latest.json` 和 `holidays.json`，jsDelivr 对仓库体积有上限（具体数值未查证），仓库被 APK 撑大后可能读不到这两个文件。
- **`holidays.json` 和 `latest.json` 要在同一次提交里一起提交。** App 用 `latest.json` 里的 SHA-256 核对 `holidays.json`，只提交其中一个，另一边就会对不上而被拒绝。
- `downloadUrls` 默认按 `kRepo` 拼 Release 页面（Gitee 在前），也可以用 `--download-url` 指定（可重复）。`kRepo` 还是占位符时脚本会给出警告。
- **只更新节假日表、不发版**：改 `shu_schedule/assets/holidays.json`（顶层 `version` 保持 1，`updatedAt` 改成当天），再运行 `python shu_schedule/tool/gen_latest.py --refresh-holidays --out latest.json`，把两个文件一起提交。App 只在远程的 `updatedAt` 比手里的新时才替换（整份替换，不逐条合并）；文件要保持 UTF-8、LF 换行、不超过 256 KiB。jsDelivr 有缓存，新文件可能要过一阵才对所有人生效。

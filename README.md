# 简课表

一个干净的大学课程表 App（Android）。**无广告、无账号、不上传任何数据**，所有课表都只存在你自己的手机里。

- **教务一键导入**：在学校自己的教务网页里登录，点一下就把本学期课表读进来（目前内置支持正方教务，上海大学已验证；其他学校可以输入教务网址尝试）
- **导不进来也不怕**：同学之间「分享此课表」一个文件就能导入；手动录入有「保存并继续添加」「复制到其他星期」「教师 / 教室自动补全」「长按空格子新建」
- **好看的周课表**：今天整列高亮、正在上的课带进度、单双周、午间 / 晚间休息带按作息自动画
- **调休 / 停课**：国庆调休「周六上周一的课」、运动会停课，按日期设置一次，周课表、今日页、桌面小组件一起生效
- **桌面小组件**：当天课程，◀ ▶ 切换日期，课多了上下滑动；在 App 里一键弹出系统的「添加到桌面」
- **长按 App 图标**：「今日课程 / 导入课表 / 添加桌面小组件」三个快捷方式
- 6 套主题、多课表、作息 / 开学日期 / 总周数随便改、备份导出导入、每天最多一次的新版本提醒

> 1.3.0 起 App 改名为「简课表」（以前叫「上大课表」）。包名没变，**直接覆盖安装，课表不会丢**。

## 一、下载与安装

### 1. 选哪个安装包

| 文件 | 用途 |
|---|---|
| `简课表-v1.3.0-arm64.apk` | **绝大多数人用这个。** 2018 年以后的安卓手机基本都是 arm64，体积小一半 |
| `简课表-v1.3.0.apk` | 通用包（arm64 / armeabi-v7a / x86_64 都在里面）。装 arm64 包提示「解析包错误」「应用未安装」时改用它 |

两个包功能完全一样。不确定就先装 arm64 的，装不上再换通用包。

下载地址：GitHub Releases（发布时补上链接）。App 里的「设置 → 检查更新」也会在有新版时直接带你去下载页。

### 2. 允许安装「未知来源」的应用

不是从应用商店装的，系统会拦一下，按手机品牌操作（不同系统版本的菜单名可能略有差别）：

- **通用（Android 8 及以上）**：点开 APK → 提示「不允许安装来自此来源的应用」→ 点「设置」→ 打开「允许来自此来源」→ 返回继续安装。这个开关是**给某个 App 的**（比如「文件管理」或浏览器），装完可以再关掉。
- **华为 / 荣耀**：
  - 先看**纯净模式**：EMUI 12 / HarmonyOS 2~4 默认开着「纯净模式」，会直接拦下商店外的应用。到「设置 → 系统和更新 → 纯净模式」点「退出」（部分版本在「设置 → 安全」里），装完可以再打开。
  - 再允许外部来源：「设置 → 安全 → 更多安全设置 → 外部来源应用下载」，给你用来打开 APK 的 App 打开开关。
  - **HarmonyOS NEXT（纯血鸿蒙 5 及以后）不能安装 APK**，暂时没有办法。
- **小米 / 红米（MIUI / HyperOS）**：安装时如果提示风险，选「继续安装」；可能要求等待几秒或登录小米账号。也可以在「设置 → 隐私保护 → 特殊权限 → 安装未知应用」里给对应的 App 打开。
- **OPPO / 一加 / realme（ColorOS）**：安装时会做「安全检测」，等它扫完点「继续安装」；如果被拦，在「设置 → 安全 → 安装外部来源应用」里打开。
- **vivo / iQOO（OriginOS）**：「设置 → 安全与隐私 → 更多安全设置 → 安装未知应用」，给对应的 App 打开；安装时提示风险选「继续安装」。

提示「此应用未经检测 / 可能有风险」是所有商店外 APK 的通用提示，选「仍然安装」即可。

### 3. 升级

直接安装新版 APK 覆盖即可，课表、主题、设置都会保留（包括从「上大课表」1.2.0 升级到「简课表」1.3.0）。
**请始终用同一个来源的安装包**：签名不同的包系统会要求先卸载旧版，卸载会清空课表——真遇到这种情况，先「设置 → 导出备份」。

第一次打开（以及从旧版本升级上来后的第一次）会弹出「隐私说明」。**点「同意」之前，App 不会发出任何网络请求。** 想看全文可以点「阅读完整隐私说明」，之后也随时能在「设置 → 隐私说明」里看到。

## 三、从教务系统一键导入

入口：首页空状态的「从教务导入」、周课表右上角 ⋮ →「从教务导入」、或长按 App 图标 →「导入课表」。

1. **选学校**：可以按校名、拼音、拼音首字母搜索。列表里的标签：
   - **已验证**：开发者实际走通过；**社区 / 实验**：按同类系统推断，可能要多试几次。
   - 学校不在列表里：点最下面的「我的学校不在列表」，输入教务系统的网址（登录后浏览器地址栏里的那个）。App 能认出正方新版教务（网址里有 `/jwglxt`）时会按实验模式尝试；认不出会告诉你暂不支持，并说明怎么反馈。
2. **登录**：App 打开学校自己的登录页，用**你自己的账号**登录。账号密码直接发给学校，App 不读取也不保存。短信验证码、滑块等二次验证在页面里正常完成即可。
3. **点底部的「一键导入课表」**。按钮一直是灰的、但你确定已经进入教务系统了，就点下面那行「我已登录，直接导入」。
4. **在预览页逐项核对**（别一路点确认）：
   - 学生姓名是不是你本人；学期名是否和教务系统一致；
   - **开学日期**：识别到当前周次时会自动推算；识别不到时默认是最近的周一，并高亮提醒你改成「本学期第一周的周一」（学校有校历预设时可以直接点选）；
   - **作息时间**：默认沿用当前课表的作息，也可以换成模板；
   - 课程数量、抽查几门的星期 / 节次 / 周次 / 教室；展开「N 条提醒」看看有没有被跳过的课；
   - 「没有固定时间的课」（实践课、线上课）不会进网格，需要时手动添加。
5. 选「覆盖当前课表」或「新建课表」→ 确认。

导入完成（或离开登录页）后，App 默认会清掉教务网页的登录状态，拿到你手机的人不能直接进教务系统。想少登几次，可以在「设置 → 教务导入 → 记住教务登录」里打开。

### 扫码登录（企业微信 / 微信 / QQ）

有些学校的统一身份认证提供「企业微信 / 微信 / QQ 扫码或一键登录」。1.3.0 起在登录页点这些按钮，App 会**跳到对应的 App**（手机上要装了它），在那边确认后回到简课表继续。
如果提示「没有找到能打开这个登录方式的 App」，说明手机上没装，或者学校的这个入口只能在电脑上扫码——**改用账号密码登录**即可。

### 导不进来怎么办

按这个顺序试：

1. **请同学分享一份**：同一个班的课表几乎一样。让导入成功的同学在「设置 → 课表管理 → 某张课表右边的 ⋮ →「分享此课表」」发一个 `简课表-<课表名>-<日期>.json` 文件给你（微信 / QQ / 网盘都行），你在「设置 → 课表管理」右上角的「从文件导入课表」（或「设置 → 备份 → 从文件导入课表」）里选这个文件，就会**新建**一张课表，不会动你现有的数据。旧版「上大课表」导出的备份文件也能这样导入。
2. **手动录入**（一学期大约 10 分钟）：
   - 在周课表上**长按空格子**，直接新建这一天、这一节的课；
   - 编辑页底部的 **「保存并继续添加」**：保存后留在本页，星期 / 节次 / 周次都保留，只清空课程名、教师和教室，适合连着录同一天的课；
   - **「复制到其他星期」**：一门课一周上两三次，勾上其他几天，一次生成，改颜色时一起变；
   - 教师、教室输入时会**提示本课表里用过的值**。
3. **导出诊断样本帮忙适配**：导入失败的对话框里、或登录页右上角 ⋮ 里有「导出诊断样本」。它会在你手机上把学号、手机号、姓名等替换成 `***` 后生成一个文件，由你自己决定发给谁（可以先打开检查），App 永远不会自动上传。连同学校名称、教务网址一起通过「设置 → 反馈」发给开发者。

## 四、桌面小组件

**推荐：在 App 里一键添加。**「设置 → 添加桌面小组件」或长按 App 图标 →「添加桌面小组件」，系统会弹出「添加到桌面」确认框，点「添加」就放好了。

桌面不支持这个确认框时，App 会给出手动步骤：

1. 回到桌面，**长按桌面空白处**；
2. 点「小组件」（vivo 叫「原子组件 / 应用挂件」，部分机型叫「桌面工具」「安卓小组件」）；
3. 在列表里找到「**简课表**」；
4. **长按预览图，拖到桌面空位**。

小组件显示某一天的全部课程，◀ ▶ 切换日期（翻到非今天时右上角有「回到今天」），课多了可以上下滑动，也可以把小组件拉高。每天 0 点自动换到新的一天；改了课表或主题后 App 会主动刷新它；调休 / 停课也会反映在小组件上。很久没打开 App 时会显示「打开 App 刷新课表」。

## 五、调休与停课

「设置 → 学期设置 → 调休 / 停课 → 添加调休 / 停课」：

1. 选**日期**；
2. 选这一天怎么上课：
   - **停课**：这一天的课全部不显示（放假、运动会）；
   - **按某个星期上课**：例如国庆后的周六「按周一的课上」；需要的话还能同时指定按第几周；
   - **指定周次**：例如「这一天按第 7 周的课上」（补课），星期可以不变或另选；
3. 备注（可选），例如「国庆调休」。

设置好的日子会在周课表的日期下面标「停课」/「调休」，今日页顶部也会写明。点列表里的一条可以修改，右边的垃圾桶删除（删错了可以点「撤销」）。

## 六、设置一览

| 项目 | 说明 |
|---|---|
| **课表管理** | 新建 / 切换 / 重命名 / 删除课表；每张课表的 ⋮ 里有「分享此课表」；右上角「从文件导入课表」 |
| **学期设置** | 学期名、开学日期（第 1 周周一）、总周数、是否显示周末、调休 / 停课、示例学期预设 |
| **作息时间** | 默认是通用的 12 节示例作息。逐节改开始 / 结束时间，增加 / 删除末节，改乱了点「恢复默认」 |
| **显示非本周课程 / 格子里显示时间 / 主题** | 显示偏好；主题切换后课表、今日页、小组件一起换色 |
| **记住教务登录** | 默认关闭：导入完成或离开登录页后清除教务网页的登录状态 |
| **导出备份 / 导入备份** | 全部课表 + 设置一个 JSON 文件；导入时可以「覆盖」或「合并」 |
| **检查更新** | 每天最多自动检查一次，有新版弹出更新日志，「去下载」用浏览器打开下载页；也可以手动检查 |
| **隐私说明 / 反馈** | 反馈里可以「复制诊断信息」（App 版本、Android 版本、机型，不含任何课表） |

**建议导入完课表后立刻导出一份备份**，换手机、卸载重装之前也一定先导出。

## 七、隐私

- **零上传**：没有服务器、没有账号、没有广告和统计 SDK。课表、作息、设置只存在手机的 App 私有目录里，卸载即全部删除。
- **只在两种情况下联网**：你主动「从教务导入」时打开学校教务网页；每天最多一次检查新版本（从 GitHub 或 jsDelivr 下载一个很小的 `latest.json`，不带任何个人数据，但对方会看到你的 IP）。首次打开同意隐私说明之前，不发任何请求。学校清单内置在安装包里，不联网下载。
- **权限**：App 自己只申请 `INTERNET` 一个权限。另有 4 个由系统组件自动合并进来的普通权限（`ACCESS_NETWORK_STATE`、`WAKE_LOCK`、`RECEIVE_BOOT_COMPLETED`、`FOREGROUND_SERVICE`，来自小组件库引入的 Android 官方后台任务库），安装时自动授予、**不会弹窗**，App 没有用它们做额外的事。没有存储、相机、位置、通讯录等敏感权限。
- 完整内容见 App 内「设置 → 隐私说明」（源文件 `shu_schedule/assets/privacy.md`）。

## 八、常见问题

**周次不对 / 开学日期不对？**
周次是用「今天距离开学日期多少天」算出来的。「设置 → 学期设置 → 开学日期」改成**第 1 周的周一**（选了周中某天会自动对齐到那周周一）。判断方法：教务系统说现在是第 5 周，App 就应该显示第 5 周，差几周就把开学日期挪几个 7 天。

**总周数不对 / 后面几周的课不显示？**
「设置 → 学期设置 → 总周数」改大。

**上课时间和学校不一样？**
「设置 → 作息时间」逐节改；午间 / 晚间休息带会按作息自动画（相邻两节间隔 40 分钟以上的地方）。

**导入失败的常见提示**

| 提示 | 怎么办 |
|---|---|
| 未登录 / 登录已失效 | 回到教务首页重新登录，看到教务系统菜单后再点导入 |
| 请求教务接口失败 / 网页加载失败 | 多半是网络：不少学校**校外访问教务要连学校 VPN**，连上校园网或 VPN 再试 |
| 抓取超时 | 教务系统太慢，确认网页里能看到课表后稍等再试 |
| 没有解析到任何课程 | 教务默认选中的学期不对，在网页里手动切到正确学期查询一次，再点导入 |
| 返回的内容不是 JSON / 接口可能已经变化 | 学校改了系统，请导出诊断样本并反馈 |

实在导不进来，看上面「导不进来怎么办」：请同学分享、手动录入、导出诊断样本。

**小组件的「正在上 / 下一节」高亮不及时？**
系统限制小组件最快约 30 分钟刷新一次，被省电策略限制时会更久。打开一次 App 会立刻刷新。App 不会为此申请自启动或精确闹钟权限。

**同一时间有两门课？**
网格里画第一门，右上角有 `+N` 角标，点开详情能看到全部。

**会不会上传我的课表？**
不会。见上面「隐私」。

**怎么反馈问题？**
「设置 → 反馈」：复制诊断信息，连同问题描述、截图一起发给开发者（GitHub Issues 地址发布时补上）。导入相关的问题请附上诊断样本。会用电脑的话，也可以附一份日志：

```bash
adb logcat -c
# ……在手机上把出问题的操作重做一遍……
adb logcat -d -s flutter chromium > jiankebiao_log.txt
```

## 九、已知限制

1. 只有 Android 版；HarmonyOS NEXT（纯血鸿蒙）和 iOS 暂不支持。
2. 一键导入目前只内置了正方新版教务（`jwglxt`），只有上海大学经过实际验证；其他系统（强智、青果、URP 等）还不支持，请用分享 / 手动录入。
3. 没有课前提醒、没有 ICS 导出、没有云同步。
4. 检查更新只会提示并打开浏览器，不会在 App 内下载安装（那需要额外的「安装未知应用」权限）。
